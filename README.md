# Binarios grandes de Advanced Security Systems

GitHub no admite archivos de más de 100 MB en un repositorio. `advsec_lockers.pbo` (taquillas TS_Lockers, 400 MB) va aquí dividido en partes.

1. Descarga esta rama (Code → Download ZIP).
2. En `lockers\`, ejecuta `UNIR.bat`: crea `advsec_lockers.pbo`.
3. Copia `advsec_lockers.pbo` y `advsec_lockers.pbo.advsec_<versión>.bisign` a `@AdvancedSecuritySystems\addons\`.
